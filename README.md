## What this app is about

This app is a simple habit and routine tracker that helps users organize their daily tasks, build consistency, and stay motivated over time. It allows users to add habits, track progress, and manage their personal goals in a clean and easy-to-use interface.

### Features

- Add and manage personal habits
- Track progress over time
- Keep a simple and organized daily routine
- Stay focused on personal goals and consistency
